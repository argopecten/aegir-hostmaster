# Aegir GitHub Wiki Sync

Use this skill when updating or troubleshooting documentation publishing.

## Rule

- Edit docs in `doc/` only.
- Wiki is synced automatically by workflow; do not edit wiki directly.

## Trigger

- Sync runs on matching branches when `doc/*.md` changes.
